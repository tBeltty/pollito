Built for clear team consensus

Engineered for engineering leads and remote agencies who need decisions resolved without thread clutter.

App Home Dashboard

Review team participation rates, active ballots, and consensus history directly inside Slack. Export CSV logs for audit trails without an external web portal.

Double-Urn Secret Ballots

Salted HMAC-SHA256 tokens isolate voter IDs from submitted options. Database tallies record votes without storing any link back to the voter.

Automated Quorum Closing

Define a participation threshold per channel. Pollito tallies incoming votes dynamically, locks the ballot once quorum is reached, and posts the final resolution.

Targeted Follow-Up DMs

Automated reminders route exclusively to teammates who have not cast a ballot. Reminders fire without exposing who already participated.

Rate-Limited Event Queue

An in-memory queue paces concurrent votes across Slack Web API endpoints, preventing HTTP 429 rate limits during large standups or all-hands meetings.

Least-Privilege Scopes

Operates without message history reading, calendar access, or third-party AI processing. Clears enterprise InfoSec review on day one.
