Built for clear team consensus

Engineered for engineering leads and remote agencies who need decisions resolved without thread clutter.

🏠

"El Nido" App Home

A full analytical command center inside Slack. View team participation rates, active polls, past consensus records, and export CSVs without logging into an external site.

🔒

Double-Urn Secret Ballots

Real cryptographic anonymity. User participation is isolated from cast votes using HMAC-SHA256 salted tokens. Even database administrators cannot link users to their choices.

🎯

Quorum Auto-Closing

Set a quorum target (e.g. 75% of channel members). The moment the threshold is met, Pollito closes the vote, highlights the winner, and notifies the channel.

🔔

Smart Nudge DMs

Polite automated reminders sent exclusively to teammates who have not yet voted, protecting the anonymity of everyone who already participated.

Sub-Second Updates

Built with an intelligent rate-limit queue. Handles dozens of concurrent votes without triggering Slack API 429 errors or duplicate messages.

No calendar access, no message history snooping, zero AI API data leakage. Passes enterprise IT reviews with least-privilege bot scopes.
