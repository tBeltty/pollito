# Pollito

A modern Slack application integrating automated workflows, intelligent agents, and repository management.

## Tech Stack (Planned)
- Node.js (TypeScript) + `@slack/bolt`
- Dual transport: Socket Mode (local dev) & ExpressReceiver (production)
- GitHub API integration (`@octokit/rest` / Webhooks)
- Vitest for automated testing
- GitHub Actions CI/CD
