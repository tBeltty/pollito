# Internationalization (i18n) & Localization (l10n) Guidelines

This document details the architectural standards, catalog conventions, and linguistic rules for Pollito's bilingual localization system across the Slack application and the public website.

---

## 1. Architectural Principles

Pollito supports **English (base/default: `en`)** and **Spanish (`es`)**.

All code identifiers, TypeScript types, database schema attributes, API routes, and internal comments remain in **English**. Localized content is strictly confined to user-facing strings in message catalogs and static HTML templates.

### Core Guarantees
1. **Type-Safe Key Parity**: Message keys are defined as a strict TypeScript union type (`MessageKey`). Catalogs in all supported languages must provide 100% key parity at compile time.
2. **Safe ICU Formatting**: A lightweight, zero-dependency parser handles parameters (`{name}`), plurals (`{count, plural, =0 {..} one {..} other {..}}`), and selectors without eval or dynamic code execution.
3. **Pure & Clock-Free UI Builders**: Slack Block Kit builders (`src/slack/ui/views/`) never query databases or access the system clock. They accept a `Translator` instance as an explicit argument and render deterministically.
4. **Deterministic Fallback**: If a key or translation is missing in any language, the system transparently falls back to the English source text.

## 2. Slack In-App Localization (`src/i18n/`)

### Directory Structure
```
src/i18n/
├── index.ts             # Locale definitions, Translator class, resolution helpers
├── messageFormat.ts     # Minimal ICU parser and ECMAScript Intl formatters
└── catalogs/
    ├── en.ts            # Canonical English source catalog (typed MessageCatalog)
    └── es.ts            # Spanish catalog (100% key parity required)
```

### Locale Resolution Hierarchy
When an event or interaction arrives from Slack, the user's effective locale resolves using the following priority:
1. **Slack User Profile**: The locale returned by Slack's `users.info` API (e.g., `es-ES`, `es-419`, `en-US`), cached in memory with a 1-hour TTL.
2. **Workspace Default**: The workspace-wide locale stored in `WorkspaceSettings.locale` (configured by workspace admins via `/pollito` Settings modal).
3. **Global Default**: English (`en`).

```typescript
import { resolveRequestLocale, getRequestTranslator } from '../slack/utils/locale.js';

// Inside a Bolt action, command, or view handler:
const translator = await getRequestTranslator({ client, body, context });
const title = translator.t('home.title');
```

For persistent entities such as `Poll`, the creator's locale is recorded at creation time in `Poll.locale` so that background workers (such as auto-closing timers) announce results in the poll's established language:

```typescript
import { getPollTranslator } from '../slack/utils/locale.js';

// Inside background workers or nudge routines:
const pollTranslator = getPollTranslator(poll);
await client.chat.postMessage({
  channel: poll.channelId,
  text: pollTranslator.t('poll.closed.notification', { title: poll.question })
});
```

## 3. Formatting & Standard ECMAScript `Intl` APIs

Avoid manual string concatenation for numbers, dates, lists, and relative intervals. Always use the built-in methods on `Translator`:

- **Plurals (ICU MessageFormat)**:
  ```typescript
  // Catalog definition:
  'vote.count': '{count, plural, =0 {No votes yet} one {# vote} other {# votes}}'

  // Output:
  t('vote.count', { count: 1 }) // "1 vote"
  t('vote.count', { count: 5 }) // "5 votes"
  ```
- **Numbers**: `translator.formatNumber(12500)` → `12,500` (EN) / `12.500` (ES).
- **Dates & Times**: `translator.formatDate(poll.createdAt, { dateStyle: 'medium', timeStyle: 'short' })`.
- **Relative Time**: `translator.formatRelativeTime(-15, 'minute')` → `"15 minutes ago"` (EN) / `"hace 15 minutos"` (ES).
- **Lists**: `translator.formatList(['Alice', 'Bob', 'Carlos'])` → `"Alice, Bob, and Carlos"` (EN) / `"Alice, Bob y Carlos"` (ES).

## 4. Slack Block Kit Constraints & Text Expansion

Spanish text naturally expands between **20% and 45%** relative to English. All Slack Block Kit components must adhere to hard platform constraints in both languages:

| Component | Slack Limit | Guideline |
| :--- | :--- | :--- |
| **Modal Title** | 24 characters | Keep concise: `"Pollito"` or `"Ajustes"` |
| **Button Text** | 75 characters | Aim for under 30 characters: `"Votar"` / `"Cerrar votación"` |
| **Option Label** | 75 characters | Allow user content, but trim operational suffixes |
| **Section Text** | 3,000 characters | Use standard paragraph breaks; avoid deep block nesting |
| **Context Text** | 2,000 characters | Format timestamps and voter counts concisely |

## 5. Website Localization Architecture (`public/`)

The public marketing site supports bilingual search indexing and browsing:

- **Routing & Canonical URLs**:
  - English (Default): `https://pollito.tbelt.online/` (mirrored at `/en/`).
  - Spanish: `https://pollito.tbelt.online/es/`.
- **Bidirectional `hreflang` Tags**:
  Every HTML page includes reciprocal `link` elements for `en`, `es`, and `x-default`:
  ```html
  <link rel="canonical" href="https://pollito.tbelt.online/es/">
  <link rel="alternate" hreflang="x-default" href="https://pollito.tbelt.online/">
  <link rel="alternate" hreflang="en" href="https://pollito.tbelt.online/">
  <link rel="alternate" hreflang="es" href="https://pollito.tbelt.online/es/">
  ```
- **Sitemap**: `public/sitemap.xml` includes `<xhtml:link rel="alternate" ...>` for every published page.
- **Interactive Simulator (`public/app.js`)**: Detects `<html lang="es">` or `/es/` pathname and renders Spanish poll cards and status updates dynamically.

## 6. Spanish Editorial & Linguistic Standards

When translating or authoring Spanish copy:

1. **100% Strict Tuteo (`tú` / `tu`)**: Never use voseo or formal *usted* in user-facing copy. Address users directly: *«Crea tu primera votación»*, *«Puedes ajustar los valores»*.
2. **RAE Punctuation**: Always open interrogative and exclamatory sentences with inverted punctuation marks: *«¿Las votaciones son públicas o anónimas?»*, *«¡Votación cerrada!»*.
3. **Anti-AI Slop**:
   - Zero binary contrasts (*"no es una simple herramienta, sino..."*).
   - Zero throat-clearing (*"En el mundo actual del trabajo remoto..."*).
   - Zero corporate buzzwords (*"revolucionario"*, *"sin fisuras"*, *"robusto"*).
4. **Technical Accuracy**:
   - *Ballot*: «Papeleta» / «Votación»
   - *Secret Ballot*: «Papeleta secreta» o «Voto anónimo»
   - *Double-Urn*: «Doble urna criptográfica»
   - *Quorum*: «Quórum» (con tilde en español)
   - *Nudge*: «Recordatorio sutil» o «Aviso»
